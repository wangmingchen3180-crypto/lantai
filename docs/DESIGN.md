# 视觉与涟漪设计语言

澜台的识别符号是涟漪，不是系统图标 `sparkles`，也不是心电图 `waveform.path.ecg`。这份记录把已经落地的规格、还没做的身份件、以及实验室里被否决的路线写在一起，避免以后重新开一轮「要不要像水」。

对照原型：

- 定稿预览：[ripple-selection-preview.html](prototypes/ripple-selection-preview.html)（方向 A，已写入 `CPRippleView`）
- 三条路线对比：[ripple-style-lab.html](prototypes/ripple-style-lab.html)（实验室，不是产品依据）
- [multitask-status-prototype.html](../multitask-status-prototype.html) 已被否决，不要当设计依据，也不要提交到公开仓库

## 已经落地：运行时涟漪

原生实现是 `CPRippleView`（`Sources/CodexPulse/CPControls.m`）。规格来自定稿预览，用两层描边 CALayer 近似「亮峰 + 暗谷」，没有上 Core Image 折射滤镜——小尺寸里滤镜成本高，观感收益不够。

| 项 | 规格 |
| --- | --- |
| 层数 | 8 层同心波，每层一对：白峰 + 黑谷 |
| 扩散 | scale `1.0 → 1.55`，线宽 `2.0 → 0.5` |
| 曲线 | `cubic-bezier(0.45, 0.08, 0.35, 1)`，出发极平缓 |
| 基准周期 | 运行中 12s，层间错峰 1.5s（周期 / 8） |
| 状态只改周期 | 失败 8s · 等待 9.6s · 完成待查验 10.8s · 运行中 12s · 待机 14s |
| 叠放 | 波层在图标之下，从图标边缘的水面露出，不遮挡图标 |
| HUD | 只有**选中**的 Agent 起涟漪（「选谁听谁」） |
| 悬浮球 | 常开涟漪，表示「有东西在活着」 |
| hover | 环提亮一档，不起涟漪 |
| 减少动态效果 | 停掉全部 CAAnimation，只留固定状态环 |

层数、曲线、错峰比例不随状态变。颜色继续绑定状态语义，不绑皮肤。

## 还没做：身份件

运行时已经会荡水，品牌识别里还没有水。现在三处入口用的都是系统符号：

| 位置 | 现状 | 应改成 |
| --- | --- | --- |
| 菜单栏 | `CPStatusSymbol` 按状态换符号：`sparkles` / `pause.fill` / `exclamationmark.bubble.fill` / `checkmark.circle.fill` / `xmark.octagon.fill` / `moon.zzz.fill` | **同一套**同心弧模板图标，用 `contentTintColor` 染状态色 |
| 悬浮球中心 | `waveform.path.ecg` | 静止的同心弧，与 `CPRippleView` 同几何 |
| 工作台标题旁、快捷栏「工作台」按钮 | 同上 `waveform.path.ecg` | 同上 |

菜单栏按状态换符号，等于在教用户「图标才是状态」。涟漪语言要求反过来：形状永远是水面，状态只走颜色和周期。菜单栏 16pt 画不下八层运动波，所以那里只放静止的 2～3 圈弧，当模板图像（黑画、系统染色），浅色/深色菜单栏分别验可辨识度。不要在菜单栏上开 CAAnimation。

### Logo / 应用图标

静止形态就是 `CPRippleView` 去掉动画：同一圆心、同一套弧、2～3 圈。深色底上用亮弧，导出时再出一版单色模板给菜单栏。App 是 `LSUIElement`，不占 Dock，但 Finder、「关于」、GitHub 和以后的公证签名都需要 1024 应用图标。先做矢量源文件，再导出：

- 菜单栏模板：16 / 32 pt
- 悬浮球中心：约 22 pt
- 工作台 / 快捷栏：14～16 pt
- App 图标：1024

不要另画一个「更漂亮的」无关图形。Logo 和运行时涟漪必须是同一个东西的两个状态。

### 空状态

「当前没有任务」和「数据源不可用」现在都是一行 muted 文字。前者应画一圈静止水面（平静，不是加载失败）；后者保持明确的「数据源不可用」，不要画成空水面——那正是 Codex 静默空列表的视觉版。

## 明确不铺涟漪的地方

任务卡、待办行、按钮、返回入口。涟漪只表示「有东西在活着」。全都在动等于都不动。

## 实验室三条路线，不要重开

`ripple-style-lab.html` 比过三条：

1. **折射**：波沉在水面层，需要滤镜。预览定稿采用了它的周期、层数和「从圆心出发」。
2. **明暗双环**：两层描边，落地成本最低。原生 `CPRippleView` 实际走的是这条实现。
3. **极简单环**：放弃像水。否决，因为名字已经叫澜台，涟漪必须能被认成水。

以后不要再从这三条里重选。要改，只改身份件（图标、Logo、空状态），不动已经写入自测的周期和层数。

## 皮肤边界

皮肤换背景、表面、强调色、文字。涟漪的几何、环数、速度不随皮肤变。状态灯是语义色，倾向固定。详见 `BACKLOG.md` 皮肤一节。
